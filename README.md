# SablieR

髪とお菓子と古道具、SablieRのサンプルサイト。

## 閲覧

https://crestix-company.github.io/SablieR/

## 構成

HTML・CSS・JavaScriptの静的サイトです。ビルドやパッケージのインストールは不要です。

- `index.html` — 店舗紹介、髪・お菓子・古道具、店舗案内
- `style.css` — PC・スマートフォンのレイアウト
- `app.js` — 写真ギャラリー、拡大表示、モバイルメニュー
- `assets/` — 支給ロゴ・写真

## 公開設定

GitHub Pagesの公開元は `main` ブランチのルート `/` です。
`.nojekyll` により静的ファイルをそのまま配信します。
画像・CSS・JavaScriptの参照は相対パスで、`/SablieR/` 配下で動作します。
サンプルとして検索結果への掲載を避けるため `noindex, nofollow` を指定しています。
本公開時はこの指定と `og:url` / `og:image` を確認してください。

## 編集時の注意

支給文章・写真と各部門の対応を維持してください。
営業時間と料金は資料に記載がないため、具体的な数値は掲載していません。
公式LINEはヘッダーと店舗案内の2か所に設置しています。

## ローカル表示

`index.html` をブラウザで開くか、このディレクトリを任意の静的HTTPサーバーで配信してください。
